# Product Workflows

## Estimation Loop

1. Create or reopen a named room.
2. Join with a display name, avatar, and voter or spectator role.
3. Voters submit hidden cards; the roster groups voters and spectators, labels online/offline presence, and shows a yellow `No vote` or green `Voted` card without exposing estimates.
4. Anyone may reveal, manually start a confirmed 1-, 3-, 5-, or 10-second countdown, or let the countdown start automatically when all voters submit.
5. Review revealed cards, rounded-up average, and recommendation.
6. Start the next round, which clears current votes.

Room owners manage the persisted room theme and fun level. The room directory supports owner shutdown; non-owners need the configured shutdown PIN.
